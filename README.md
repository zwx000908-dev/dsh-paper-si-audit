# dsh-paper-si-audit

**Paper–SI Audit** 是面向科研论文的 DeepSeek Harness 插件，帮助作者核对论文正文与补充信息（Supplementary Information，SI）中的数据、实验描述和表征信息。它将待核实的问题与对应原文、来源位置和计算依据一起呈现，便于研究者回到材料中逐项判断。

项目首先面向化学论文中的常见数据场景，也可用于插件当前规则支持的其他科学论文数据。

## 可以用来做什么

- **核对正文与 SI**：针对可识别的产率、ee/er、部分实验条件和表征数据，查找值得复核的不一致或对应关系。比较时保留实验、批次、条件和方法等上下文，避免仅凭相同编号判断为同一实验。
- **检查数据格式**：使用 JSON 或 YAML 自定义模板，为不同字段设置小数位、有效数字、舍入方式和单位。例如，可以分别设置 ¹H、¹³C 化学位移、偶合常数 J 和 HRMS 数值的显示要求。用户可以记录规则来源；插件不会自行认定某项设置是期刊要求。
- **读取图像表格**：选择 PDF 页、DOCX 嵌入图片或单独的图像文件，使用本地 OCR 提取候选表格。结果保留原件与图像哈希、单元格位置和原始识别文字，供人工对照、校正和确认。
- **复算 HRMS/MS 精确质量**：根据支持的分子式、同位素、加合物和电荷计算理论 m/z，并分别检查报告的 calculated 数值和 found 数值偏差。分子式究竟表示中性分子还是最终离子不明确时，保留候选解释，不依据哪个值更接近来决定口径。
- **核对核磁与分子式**：将同一化合物记录中的 ¹H 报告积分总数、¹³C 信号及标注碳数与分子式对应。有嫌疑的记录、分子式口径歧义和无法完整读取的记录分别列出，附原文引用。考虑交换氢、对称性、重叠及多重峰，结果供人工复核。
- **按图片类型筛查重复**：显微图/照片支持整图、方向变换及有限局部匹配；条带默认保持方向；谱图、图表、反应式、整页和未分类图片默认只查精确重复，避免把共用坐标轴当成相同数据。类型和规则可自定义，候选保留源位置及哈希。此前像素算法的外部真实图片检出能力不足，不能凭零告警认定无重复。
- **组织化合物材料**：建立候选化合物档案，关联表征文字和图片；用户可确认归属，按新化合物、已知化合物等类别设置材料清单，区分未定位、已定位未读取及已读取。
- **核对谱图标注与实验数字**：比较核磁文字与图像内明确标签或有独立引用的谱图标题；支持收率、质量/物质的量及浓度复算，保留假设、容差、原文和人工更正历史。
- **核对图表与结论**：定位明确图表引用，比较可解析表格中的最高值、指定 entry 或化合物数值；方法不同或证据不足时不强判。
- **追踪修订与整篇进度**：保存旧问题的复核台账，疑似修复需用户确认；整篇图像渲染/OCR 和分批比较可中断续跑，列明失败与覆盖边界。
- **保留证据和结果**：查看来源文字及位置、记录人工复核意见，导出 Markdown、JSON 或 CSV 报告。运行记录保存来源、规则和复核快照，方便后续修订时重新核对。

- **视觉 Agent 图片复核**：将原图和高清裁剪交给当前支持图片输入的 Harness 模型，独立生成图片对任务，保存对应区域和判断依据，生成对照图并保留更正历史。任务可恢复；图像未成功提供时明确失败。[用法与能力边界](docs/VISUAL-AGENT-0.8.md)。
- **按共同原因复核**：将依赖同一通用方法、局部分子式解释、格式规则或图像对的问题集中阅读，保留每条原始问题和局部例外；修正共同依据后重新核对，逐条闭环。

分类规则、原生工具用法与外部验证见 [复核工作流](docs/REVIEW-0.7.md)。多论文外部标注验证覆盖 10 篇论文、172 对图像；旧像素算法对 22 对标注重复候选检出 0 对，这不是视觉模型流程的成绩；具体误报、漏报和弃判已公开，结果不支持真实图片查重可靠性的声明。

## 安装

`main` 分支开发版本为 **0.8.0**，包含化合物档案、完整性清单、局部图片查重、谱图标注互查及实验复算；已打标签的稳定安装包仍为 **0.2.0**。兼容目标为 **DeepSeek Harness 0.2.2-rc.1**，源码开发和命令行环境需要 Node.js **24.9.0 或以上**。

要使用包含上述检查的开发版本：

```powershell
dsh plugin --profile paper-audit add "github:zwx000908-dev/dsh-paper-si-audit#main"
```

以下为此前的 v0.2.0 稳定版本安装方式，不包含核磁—分子式核对和图片查重：

在已安装的目标版本 Harness CLI 中，可以从 GitHub 安装到一个独立的 `paper-audit` profile：

```powershell
dsh --version
dsh plugin --profile paper-audit add "github:zwx000908-dev/dsh-paper-si-audit#v0.2.0"
```

也可以从 [v0.2.0 Release](https://github.com/zwx000908-dev/dsh-paper-si-audit/releases/tag/v0.2.0) 下载 `dsh-paper-si-audit-0.2.0.tgz`，核对同页提供的 SHA-256 后安装：

```powershell
dsh plugin --profile paper-audit add ./dsh-paper-si-audit-0.2.0.tgz
```

上述命令操作的是独立的 `paper-audit` profile。若要在桌面版使用，请在对应的 **desktop profile** 中安装并启用 bundle，设置项目数据目录 `dataDir` 和允许读取论文的目录 `allowedRoots`，然后按宿主提示重开会话或重启。默认空的 `allowedRoots` 不允许读取本地论文。安装、配置和原生工具注册的详细步骤见 [Harness 安装与使用说明](docs/HARNESS.md)。

## 使用方法

准备好论文正文、SI 和需要使用的格式规则后，可以直接在已启用插件的 Harness 会话中输入：

> 请使用 Paper–SI Audit 创建核对项目，导入我指定的论文正文和补充信息。先报告文件解析覆盖范围，再按我提供的格式模板检查数据与格式。对图像中的表格，先列出可选页面或图片，只读取我指定的部分，并让我对照原图确认。对含明确分子式的 MS 数据进行精确质量复算；如果分子式口径不明确，请保留候选解释。最后列出需要复核的问题及原文证据，并导出 Markdown 和 JSON 报告。

一般核对流程如下：

1. **建立项目并导入材料**：按正文 `main`、补充信息 `si` 或其他来源 `source` 指定文件角色。
2. **查看解析覆盖**：确认哪些页面、文字、表格或图像被读取，以及哪些内容未能解析。
3. **选择格式模板**：导入并保存用户自己的 JSON/YAML 模板，再运行核对。示例 [custom-demo.yaml](profiles/custom-demo.yaml) 展示了规则写法，并非期刊标准。
4. **复核图像与计算**：选定需要读取的图像表格，对照原图确认或更正 OCR 文字；对质量复算确认分子式口径和离子形式。
5. **查看证据并导出**：逐条检查重要候选的原文或单元格位置，记录处理意见，导出报告。材料或规则更新后可创建新的核对运行。

对于分子式复算，也可以单独要求 Harness 计算，例如：“按中性分子式 C2H6O 和离子 [M+H]+ 复算理论 m/z。”

核磁与图片核对可直接要求：

> 请核对正文和 SI 中的核磁数据与各自分子式是否相容，把积分不符、碳数超出、分子式歧义和信息不足的记录列出。对我导入的文档和科研图片逐批准备查重素材，跟进 nextOffset 后运行核对；列出完全重复与疑似相似的图片及两端位置。明确未读图片、PDF 整页比较的局限以及超过处理上限的材料。

核磁文本检查随 `paper_audit_run` 自动执行。图片先用 `paper_audit_prepare_image_audit` 对每个来源的 `documentKey` 分批提取（每批 1–10 个，跟进 `nextOffset`），随后再次运行 `paper_audit_run`，在 `image_duplicate` 问题中查看候选。默认处理最多 1000 个登记素材、每次比较 2000 对；比较未结束时继续运行，同一项目保留跨批次比较进度。使用 `paper_audit_visual_image` 按候选中的 assetId 打开两端原图。通用方法继承、直接 mmol 收率、摩尔质量与条件性复算见 [实验关联说明](docs/EXPERIMENTS-0.6.md)。图表核对、实验段落解析、修订闭环和整篇续跑见 [0.5 使用说明](docs/WORKFLOW-0.5.md)。完整流程、材料清单、自定义阈值及计算示例见 [科学材料核对](docs/SCIENTIFIC-WORKFLOW.md)。

## 支持的材料与使用边界

可导入 DOCX、可检索文本的 PDF、TXT/Markdown、CSV、JSON、XLSX，以及 PNG、JPEG、单帧 TIFF、WebP、BMP 图像。DOCX/XLSX 原件上限为 128 MiB，其他输入上限为 32 MiB。原始文件以只读方式处理；报告和项目记录保存在独立数据目录。

图像表格 OCR 使用本地英文模型，复杂合并格、低清扫描、手写、上下标和特殊符号需要人工对照。图像附件能否进入当前模型取决于 Harness 和模型的实际能力；未能识别或未选择读取的内容会保留在覆盖范围中。

精确质量复算依赖分子式、加合物、电荷和计算口径，不能单独证明化学结构、谱图或测量结果的真实性。软件默认的 ppm 阈值仅用于提示，不自动代表期刊或仪器要求。当前工具也不完成原始谱图确证、完整质量平衡、全文图表引用核对或 Word 自动写回。

语义候选由当前 Harness 会话的模型辅助判断；进入会话的文字或图像可能进入宿主模型及日志，具体取决于你的 Harness 配置。核对报告应结合解析覆盖和人工判断使用；没有告警不代表全部论文数据已经核实。

详细能力与验证范围见 [图像表格说明](docs/IMAGE-TABLES.md)、[HRMS 复算说明](docs/HRMS.md) 和 [验证记录](docs/VALIDATION.md)。
