# 0.10.2 项目检查记录

日期：2026-11-10。检查对象为源码、自动测试、安装包和 DeepSeek Harness 0.2.2-rc.1 原生工具集成。

## 已修复的问题

1. 多个图片任务只汇总最后一个任务，可能遗漏前一批已提交的疑点。现在按项目汇总来源仍有效且核对范围一致的全部登记任务，旧项目重新运行核对即可使用；不改写旧报告。
2. 设置保存成功、宿主配置刷新尚未返回时，输入框会回填旧值。现在保存接口返回宿主实际配置及修订号，客户端立即更新共享设置缓存，并保护已确认值不被迟到的旧快照覆盖。

- 完整测试 232/232 通过，覆盖解析、实体关联、HRMS、核磁计数、实验复算、图片与表格、项目设置、任务恢复、修订台账及报告。
- 新增七项回归测试：五项视觉任务汇总测试、两项保存时序测试。覆盖不同批次、无中间报告、进程重启、MD/JSON/CSV 导出、重复配对、判断冲突、重新打开旧任务、取消、源变化、丢失任务文件、核对范围隔离、连续保存、外部修改和修订号重置。

- 语法检查通过。14 个固定合成案例评估通过；结果仅说明这些案例的行为，不代表真实论文的科学准确率。

## 汇总规则

同一图片对在多个任务中的观察都保留，已观察对数去重。不同判断记录在 `conflictingPairs` 中；保留疑点，不以新的否定观察自动关闭旧疑点。`decisionCounts` 按图片对计数，有冲突时依次采用疑似重复、不确定、可能合理复用、未发现对应作保守统计；具体各次判断仍在 records 中。

重新打开某次观察后，该次结果暂不计入当前问题；其他任务的有效观察不受影响。取消或源失效的观察保留为历史记录。不同范围的任务单独标记，不混入当前报告。任务文件缺失会列出覆盖缺口。每个任务自己的预算与排除范围仍保留，因此多批次合并并不自动构成全文覆盖。
