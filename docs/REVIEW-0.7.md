# 分类查重、共同原因复核与外部验证（0.7.0）

## 按图片类型选择规则

先用 `paper_audit_visuals` 查看材料；按用户明确的类型判断调用 `paper_audit_set_image_type(projectId, assetId, type, reason)`，再运行核对。类型、依据、原件/图像 SHA-256 与历史决定一起保存；原件变动必须重新准备，重复准备相同图像保留分类。分类或规则变化使旧比较批次失效。

| 类型 | 默认筛查 | 注意事项 |
|---|---|---|
| microscopy / photograph | 整图、旋转/镜像、有限网格局部相似 | 需要检查原图，局部算法并非穷尽搜索 |
| blot | 整图、保持方向的有限局部相似 | 默认不旋转/镜像；条带生物学意义未验证 |
| spectrum / chart | 完全相同像素或同一媒体多次使用 | 相同轴线和模板不构成曲线相同的证据；尚无峰形/曲线配准 |
| table / reaction_scheme | 完全相同像素或同一媒体多次使用 | 数据内容/结构需走表格及化学核对 |
| mixed_page / unknown | 完全相同像素或同一媒体多次使用 | 先分面板并由用户分类；不从文件名自动确认类型 |

不同类型之间默认只比较精确重复。局部候选保留源像素框；父图与其直接裁剪图不会相互误报。图像相似分数不是概率，也不是科研不端结论。原生工具分类需用户明确决定；外部评估直接使用数据集原有类型标签。

用户可通过 `paper_audit_scientific_configure` 的 `optionsJson` 自定义 `imageTypeRules`，允许按类型调整 `whole`、`local`、`transforms`、`imageRmse`、`localImageRmse`，例如：

```json
{"imageTypeRules":{"microscopy":{"imageRmse":0.08,"localImageRmse":0.06},"blot":{"transforms":false}}}
```

未提供的类型采用默认值；科学设置调用中未提供的顶层字段重置为默认值。即使用户为谱图启用通用相似算法，也只是可产生模板误报的像素候选，并不会增加峰形识别能力。JSON 报告保留实际使用的类型、规则版本及阈值；`exactOnlyAssetIds` 明示未做非精确内容比较的材料。

## 按共同原因组织复核

`paper_audit_review_groups(projectId, runId)` 返回分组摘要，带 `groupId` 再分页读成员及逐条引用。Markdown 报告也显示分组索引。原问题总数不被压缩或修改。

- 通用方法：按**方法来源文档、源哈希、标题区块**归组，展示共同方法原文、受影响实验、各自缺项，以及被排除的局部改量/放大实验。同名 A 方法不跨文档混并。
- 摩尔质量/分子式：仅将同一原文区块的解释问题放在一起，不按相同化合物编号全局赋式。
- 格式：同一模板规则汇总，先核对模板，再逐值处理。
- 图片：同一图像对的多种候选合并复核入口，不将 A~B、B~C 推导成 A~C。

处理通用方法时，用户可给出带精确引用的 `paper_audit_experiment_context`、`scope=method` 判断，再运行核对。该动作不替代原文矛盾修正、不填充所有产物分子式、不覆盖局部条件，也不批量关闭问题。已不再出现的疑点仍走原有修订台账与明确用户复核流程。

## 外部多论文验证

固定了 BioFors 官方 EDD 测试划分的 **10 篇论文、172 对图片、147 张图像**。参考标签、图片类型和重复区域坐标来自外部作者公开标注，未调用本插件产生答案，也没有人为植入错误。按原压缩包顺序选择前 10 篇测试论文，每篇排序后至多取 5 个正例、15 个负例；这是方便抽样的分层子集，不代表自然重复发生率。

清单内容哈希采用解析后 JSON.stringify 的 UTF-8 编码，避免 Windows 换行转换误报；原图与上游标注仍严格校验原始字节哈希。冻结清单记录上游提交、标注文件哈希、每张图像哈希及压缩包字节位置。只发布清单、评估结果和下载脚本，原论文图像保持在忽略目录；插件 MIT 许可不改变第三方图像权利。上游标注仓库 LICENSE 为 CC0-1.0。

```powershell
python scripts/fetch-biofors.py
npm run evaluate:external
```

也可 `node scripts/evaluate-external.js "绝对路径/图片目录"`。目录结构为上游论文 ID/图像名；缺失、篡改或解码失败会记为弃判并以退出码 2 报告输入不完整，绝不记作正常负例。评估按论文、图片类别列 TP/FP/TN/FN 与弃判。自然漏检是测量结果，不为了让 CI 变绿而改标签。

**首次默认规则结果：TP 0、FP 0、TN 135、FN 14；正例弃判 8、负例弃判 15。22 个标注正例检出率为 0%。** 其中 FACS 映射为 chart，默认只检查精确重复，因此没有匹配的 23 对全部弃判。其余 14 个正例是现有图像匹配器的真实漏检。未据此调整阈值或筛掉困难样本。

这个结果证明外部评估可揭示真实局限，不能证明当前查重有效。图像功能仍属于有限筛查；不能据零告警出具“图片未重复”结论。该验证不涵盖有机化学全文、NMR、HRMS、实验段落和结论判断，也没有新增独立专家复核。后续改算法若使用这批失败案例，必须另留未看过的论文测试集。
