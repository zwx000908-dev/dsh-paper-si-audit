# 0.4.0 开发执行记录

按用户确认的顺序执行，兼容目标保持 DeepSeek Harness 0.2.2-rc.1。

1. 化合物档案、证据绑定、用户定义的完整性清单；自动同号关联不等同人工确认。
2. 面板提取、局部重复候选、原图坐标和标框证据；跨批次比较，记录截断和未覆盖范围。
3. 谱图标签/OCR 与核磁文字互查，确定性收率/质量/物质的量/浓度复算；保持源文件只读。
4. 回归与评估：合成正负例、真实原件只读回放及有标签子集；分别报告误报、漏报、无法判断及标签来源。

真实材料与开发者路径不随公开包分发。单篇论文及开发者标注不代表通用准确率，也不替代作者或独立专家确认。各阶段的实现和验证结果在完成后补记。

## 执行结果

四个阶段已接入核心、原生工具和报告。32 个原生工具在指定宿主实际运行通过；新增验证包括局部图片标框、跨批次比较、真实 OCR、明确人工更正历史和不可变快照。真实原件回放识别 51 个候选化合物；核磁 89 条记录中 87 条具备条件性计数比较，87 条仍保留离子口径歧义。仅渲染 4 个 SI 媒体和 2 页正文。原件与此前报告哈希不变。

真实单篇 13 个参考案例：3 条预期疑点、6 条预期正常结果、4 条保持不确定；标签由助手整理，尚无独立专家复核。没有据此声明通用准确率。详细结果见 VALIDATION.md 和 ../benchmarks/README.md。
