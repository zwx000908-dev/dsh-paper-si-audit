### 当前限制

- OCR 仅使用离线英文模型；复杂合并格、无边框排版、低清和化学结构均需核实。先看覆盖，再读逐格证据；用户明确接受转录不等于确认测量真实性。
- 中性分子/最终离子口径未明确时保持 ambiguous；不支持的原子、表达、电荷或不可读 found 明确披露，不能当作通过。
- 真实论文盲测、检出率/误报率、节省时间和实际宿主模型语义准确率未验收。
- 未更新或激活全局 desktop profile；当前安装/启用状态须单独检查。工作区目标运行时成功不能替代桌面会话启用。
- 未实现原始谱图确证、完整质量平衡、Word写回和全面后台恢复。源变更标记比较已登记版本；文件在项目外改动后，应重新导入或运行以更新哈希。

### 从公开源码复跑

公开版本需要 Node.js 24.9.0 或以上，与固定目标宿主一致。在仓库源码目录运行：

```powershell
npm ci
npm test
npm run check
npm run test:harness
npm run demo
```

单元/集成测试使用合成材料，并包含真实栅格 OCR；宿主冒烟使用锁定的 0.2.2-rc.1 依赖与隔离的 Harness 环境，不请求模型。新产生的 `test-output/`、`outputs/` 和项目数据仅保存在读者本地，默认不纳入 Git。`npm run demo` 展示当前规则及报告，不提供本页历史私有论文。

创建 `dist` 目录后，可运行 `npm pack --pack-destination dist --ignore-scripts`，再运行 `node scripts/verify-package.js` 检查安装包文件和解包入口。校验脚本在本地产生 `dist/package-metadata-0.2.0.json` 与 `dist/SHA256SUMS-0.2.0.txt`；公开 Release 提供哪些资产，以该 Release 的实际附件为准，仓库不预置开发者机器记录。
