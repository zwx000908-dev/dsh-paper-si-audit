# 0.1.1 真实案例修复与回归

日期：2026-11-09（Asia/Hong_Kong）。宿主目标仍为 DeepSeek Harness 0.2.2-rc.1。

## 触发与判读

开发期间，用户提供了一份 0.1.0 的真实执行报告。其独立 6 项校验验证了报告断言、引用、哈希及覆盖披露，并未证明提取正确率、真实科学错误检出率或原生工具激活成功。论文原件、报告、运行标识和机器记录保留在开发者本地，未随此仓库或安装包发布；本页仅保留匿名化的修复与验证摘要。

旧报告、旧项目、源 PDF 和源 SI 本次均未改写。修复版及新回归结果写在当前开发工作区，不自动替换桌面已安装的 0.1.0。

## 修复

1. 实体、方法、条件按局部句子和显式记录归因，避免整个 PDF 页面继承首个产物编号。多主体或关系不清时保守留空，不宣称所有归因已自动恢复。
2. 对 Table 条目、通用方法、放大和前催化剂等实验语境保留区分，未对齐时报告“实验语境待确认”。
3. 显式 EI-MS/ESI-MS calculated/found 数值进入格式检查，保留来源标签和未知分辨率；为兼容旧模板沿用 `hrms.mass_to_charge` 字段，但字段名不证明 HRMS 或质量准确性。MS 段落不再被吞入碳谱位移。
4. DOCX/XLSX 原件上限为 128 MiB，其他格式为 32 MiB。只解码受限 XML；媒体/OLE 不解压或执行，未读范围以数量、体积、哈希和视觉单元定位明确记录。
5. 新增同段明确 amount/equiv 的粗比例检查。只生成待复核候选，不决定应改 mmol、equiv 或规模表述，不替代完整质量平衡。
6. Markdown 格式提示按规则汇总，完整逐条记录仍保留于 JSON/CSV。科学数据、语义、实验对应和覆盖问题分开显示。
7. 运行记录区分 core_api、harness_native_tools、local_workbench、cli；原生入口可记录 toolCallId，仍需真实宿主日志佐证。直接调核心库不等于原生集成验收。
8. 增加只读激活诊断，并修复已保存项目的旧授权根目录绕过后续缩窄配置的问题。

## 真实原件复跑

该次修复后运行的执行入口为 `core_api`，状态为 `partial`。使用原 PDF 和 38,000,733 字节的原 SI，不使用删媒体副本。采用与旧运行相同的 custom-demo 1.0.0 用户模板，未推断期刊规定。

| 项目 | 结果 |
|---|---|
| 原文件哈希 | PDF 和 SI 的复跑前后 SHA-256 相同 |
| SI 范围 | 829 文本块；1116 单元中 1002 可读；114 个纯视觉段落未核对 |
| 未读部件 | 153 个媒体部件、152 个嵌入/OLE 对象，均在覆盖记录披露 |
| 事实数 | 2086 → 2132；新增 90 条 EI-MS 数值，并移除原被误读为碳谱的 MS 数字 |
| 原 6 条假 3a | 不再产生错误的 3a 归因/配对；部分实体仍保守未归属 |
| 剩余跨文档候选 | 3 条，均为实验语境待确认，不判同实验数值冲突 |
| MS 格式规则 | 命中 90 条事实，unmatchedRuleIds 为空；未做分子式精确质量复算 |
| 当量比例候选 | 4 处出现：正文 p9、SI ¶37、¶40、¶180，均为 high / needs_review |
| 格式提示 | 1445 条；分组展示 15 个示例，明确省略 1430 条；JSON/CSV 保留全部 |
| Markdown 长度 | 18056 行 → 1399 行 |

4 处当量提示都是基准 0.20 mmol / 1 equiv、另一组 3.0 mmol / 1.5 equiv；按该基准 1.5 equiv 应对应 0.30 mmol，相差 10 倍。4 处出现可能重复描述同一方法，**不等于 4 个独立实验错误**；正确修改仍需作者确认。

新报告仅执行修复后规则检查。旧运行的 5 条语义候选保留在旧台账，没有假装迁移为新运行的模型复核；原“缺底物名称”等事项不因本轮零语义候选而视为解决。
